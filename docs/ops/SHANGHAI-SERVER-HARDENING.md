## 5. 待处理与风险

1. 安全更新安装后需要维护窗口重启，才能加载新内核；重启会中断服务器上的既有 Node.js 业务，未擅自执行。
2. 初始 root 密码已无法用于 SSH 登录，但仍应由用户在密码管理器中生成并轮换，或在确认无需控制台密码恢复后锁定。
3. 华为云安全组不在主机 UFW 的可见范围内，需人工确认只开放 22/80/443；5003 暂未开放。
4. sysctl 应用时出现云镜像相关的非致命提示；复核确认 source route、redirect、ASLR、ptrace 和内核日志限制等目标值已加载，需在重启后再核验一次。
5. 宝塔面板和旧 Node.js 服务仍在本机监听，但相应端口已被 UFW 阻断；迁移应用前应确认这些服务是否继续保留。
