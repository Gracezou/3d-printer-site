# PRD — 3D 打印成品独立站

> 本文档面向实现 Agent。所有「必须 / 禁止」为强约束，不得自行调整。
> 配套文档：`TECH_SPEC.md`（架构）、`DATA_MODEL.md`（表结构）、`API_SPEC.md`（接口）、`TASKS.md`（执行顺序）。

---

## 1. 项目概述

一个销售 3D 打印**成品**的 DTC 独立站，含前台商城与后台管理系统。面向国内市场，人民币计价，支付宝支付。

**与普通电商的核心差异**：商品不是预先备货的实物库存，而是接单后打印。因此「是否有货」取决于**耗材库存**，而非成品库存。一个商品变体消耗一种或多种耗材，任一耗材不足则该变体不可售。

### 1.1 第一版范围

| 模块 | 包含 |
|---|---|
| 前台 | 首页、商品列表、商品详情、购物车、下单、支付、订单中心、地址管理 |
| 后台 | 订单管理、生产管理、商品管理、耗材管理、用户管理、折扣码管理、权限管理 |

### 1.2 明确不做（非目标）

以下功能**禁止**在第一版实现，但数据模型需预留位置（见 `DATA_MODEL.md`）：

- 用户上传模型定制打印（无 STL 解析、无自动报价）
- 优惠券（`user_coupons` 建表但不实现业务逻辑）
- 多语言、多币种
- 微信支付、其他支付渠道（仅做 Provider 接口预留）
- 物流 API 对接（仅人工回填单号）
- 商品评价、评分、晒单
- 会员等级、积分
- 秒杀、拼团、预售
- 多码叠加使用
- 折扣码批量生成与导出

## 3. 核心概念

| 概念 | 说明 |
|---|---|
| SPU（商品） | 一个可售商品，如「龙猫摆件」。承载标题、描述、图集、分类 |
| SKU（变体） | SPU 下的具体规格组合，如「小号 / PLA / 黑色」。承载价格与 BOM。**价格挂在 SKU 上，SPU 不直接售卖** |
| 耗材 | 一卷线材/一瓶树脂的品类，如「PLA-黑色-1.75mm」。库存以**克**为单位 |
| BOM | SKU 与耗材的关联关系，记录该 SKU 打印一件需消耗每种耗材多少克 |
| 损耗率 | 耗材级配置，默认 5%。实际扣料 = `BOM克数 × (1 + 损耗率)`，覆盖支撑材料、打印失败、料头等浪费 |
| 安全库存 | 耗材级配置，低于此值不再接受新订单占用，作为缓冲 |
| 预扣 | 下单未支付期间占用耗材（`reserved_grams`），超时自动释放 |
| 生产任务 | 每个订单项对应一个打印任务，独立流转状态 |

## 4. 核心业务规则

### 4.1 可售判定（强约束）

变体的可售数量按下式实时计算，**禁止**在商品或变体表上维护「库存数量」字段：

```
可售数量 = MIN over 所有 BOM 项 (
    FLOOR( (耗材.stock_grams - 耗材.reserved_grams - 耗材.safety_grams)
           / (BOM.grams × (1 + 耗材.waste_rate)) )
)
```

补充规则：
- 若变体的任一 BOM 耗材 `is_active = false`，可售数量为 **0**
- 若变体**未配置任何 BOM**，可售数量为 **0**（视为未配置完成，不可售）
- 计算结果为负时取 0
- 前台展示时封顶为 99，不向用户暴露真实耗材库存数量

### 4.2 库存扣减时机（强约束）

| 时机 | stock_grams | reserved_grams | 流水类型 |
|---|---|---|---|
| 创建订单 | 不变 | **+N** | `reserve` |
| 支付成功 | **-N** | **-N** | `consume` |
| 订单超时取消 | 不变 | **-N** | `reserve_release` |
| 用户主动取消（未支付） | 不变 | **-N** | `reserve_release` |
| 打印失败重打 | **-N** | 不变 | `reprint_loss` |
| 全额退款且勾选回滚 | **+N** | 不变 | `refund_return` |
| 后台入库 | **+N** | 不变 | `purchase_in` |
| 后台手动调整 | ±N | 不变 | `adjust` |

- `N` = 订单内所有订单项的 BOM 需求克数之和（含损耗率、含数量倍数）
- **所有**库存变动必须写入 `material_stock_movements` 流水表，耗材表上的数字是流水的投影
- 预扣时长：**30 分钟**（`orders.reserved_until`）

### 4.3 订单状态机

```
待支付 pending_payment
   ├─(支付成功)──→ 已支付 paid ──(自动)──→ 生产中 in_production
   ├─(用户取消)──→ 已取消 cancelled
   └─(30分钟超时)→ 已取消 cancelled

生产中 in_production ──(全部生产任务完成)──→ 待发货 pending_shipment
待发货 pending_shipment ──(后台填单号)──→ 已发货 shipped
已发货 shipped ──(用户确认收货 或 发货满 15 天自动)──→ 已完成 completed

已支付之后任一状态 ──(后台发起退款)──→ 退款中 refunding ──→ 已退款 refunded
```

状态说明：
- `paid` 为瞬态，支付回调处理成功后在同一事务内转为 `in_production`
- `in_production` 期间的细节（打印中/后处理）由 `print_jobs` 子状态表达，订单中心向用户展示聚合进度
- **禁止**跳过状态或允许逆向流转（退款除外）

### 4.4 生产任务状态机

```
待排产 queued → 打印中 printing → 后处理 post_processing → 已完成 done
                      └─(打印失败)→ 失败 failed →(重新排产)→ queued
```

- 每个 `order_items` 生成一条 `print_jobs`（数量 > 1 时不拆分，一条任务承载整个数量）
- 标记「打印失败」时：`failed_count + 1`，并触发一次 `reprint_loss` 扣料（按该订单项的完整需求量扣减）
- 订单内所有 `print_jobs` 均为 `done` 时，订单自动转 `pending_shipment`

### 4.5 折扣码规则

**可用性判定**（四个条件同时满足）：
1. `is_active = true`
2. 当前时间在 `[starts_at, ends_at]` 内（`ends_at` 为 null 表示不限）
3. `max_uses` 为 null，或 `used_count < max_uses`
4. 该用户已确认使用次数 < `per_user_limit`

**类型**：
- `permanent`（常驻）：`max_uses = null`，靠有效期和 `is_active` 控制
- `limited`（限次）：`max_uses` 为正整数

**默认值**：`per_user_limit` 默认为 **1**

**计算规则（强约束）**：
- 一个订单**只能使用一个**折扣码
- 门槛 `min_order_amount` 与减免金额**均只作用于商品小计**，运费不计入门槛、不被减免
- `percentage` 类型受 `max_discount_amount` 封顶（为 null 则不封顶）
- 减免金额**不得超过**商品小计，超出部分截断
- `free_shipping` 类型将运费置 0，不改变商品金额
- 金额计算一律由服务端执行，**禁止**采信前端传入的任何金额

**占用与释放时机（强约束）**：
- **创建订单时**占用：写入 `discount_redemptions`（状态 `occupied`）并原子递增 `used_count`，与库存预扣在**同一事务**内
- 支付成功：redemption 状态转 `confirmed`
- 订单取消/超时：redemption 转 `released`，`used_count` 递减
- 全额退款：`used_count` 递减，redemption 转 `released`
- 部分退款：**不**回滚使用次数

**并发**：`used_count` 递增必须使用条件更新，依据影响行数判断是否占用成功。禁止「先查询再写入」。

### 4.6 金额计算

```
商品小计 items_amount   = Σ(变体价格 × 数量)
折扣     discount_amount = 按 4.5 规则计算，上限为 items_amount
运费     shipping_amount = 按运费规则计算（free_shipping 类型时为 0）
应付     payable_amount  = items_amount - discount_amount + shipping_amount
```

- 所有金额字段使用 `DECIMAL(10,2)`，**禁止**使用浮点数
- 运费规则：按收货省份匹配 `shipping_rules`，首重 + 续重；商品小计达到 `free_shipping_threshold` 时免运费

## 5. 前台功能

### 5.1 首页 `/`

- 顶部导航：Logo、分类入口、搜索框、购物车图标（角标显示件数）、登录/用户菜单
- Banner 轮播区（后台可配，`settings` 表管理）
- 分类导航区：展示一级分类，带图
- 推荐商品区：展示 `is_featured = true` 且 `status = on_sale` 的商品，最多 12 个
- 新品区：按 `created_at` 倒序取 8 个在售商品
- 页脚：备案号、联系方式、关于我们

**渲染要求**：ISR，`revalidate = 300`。需输出 `Organization` 与 `WebSite` 结构化数据。

### 5.2 商品列表页 `/products` 与 `/category/[slug]`

- 筛选：分类、价格区间、材质类型（PLA/PETG/树脂等，来自变体属性）
- 排序：综合、价格升序、价格降序、最新
- 商品卡片：主图、标题、价格（展示 SPU 下最低变体价，格式「¥59 起」）、售罄角标
- 分页：每页 24 条，页码分页（利于 SEO），非无限滚动
- 空状态提示

**售罄判定**：SPU 下所有变体可售数量均为 0 时展示售罄角标。

**渲染要求**：ISR，`revalidate = 60`。

### 5.3 商品详情页 `/products/[slug]`

- 图集：主图 + 缩略图切换，支持放大
- 3D 预览（可选）：若配置了 `model_preview_url`（GLB 文件），提供交互式预览入口，可旋转缩放
- 标题、副标题、当前选中变体价格、划线价
- **变体选择器**：按属性维度分组展示（尺寸 / 材质 / 颜色）
  - 每个选项需实时反映可售状态：**不可售的选项置灰且不可点击**
  - 选中组合不可售时，加入购物车与立即购买按钮禁用，显示「暂时缺货」
  - 可售数量 < 5 时显示「仅剩 N 件」
- 数量选择器：上限为该变体可售数量与 99 中的较小值
- 加入购物车 / 立即购买
- 商品详情富文本（Markdown 渲染）
- 参数表：打印材质、成品尺寸、成品重量、预计发货时间
- 配送与售后说明

**渲染要求**：商品静态内容走 ISR（`revalidate = 60`）；**可售状态必须客户端实时拉取**（`GET /api/products/:slug/availability`），禁止缓存。

### 5.4 购物车 `/cart`

- 需登录。未登录时加入购物车跳转登录页，登录后回跳并完成加购
- 列表项：图片、商品名、变体名、单价、数量增减、小计、删除
- 每项实时校验可售状态，不可售项标记「已失效」并禁止勾选结算
- 勾选与全选，展示已选商品小计
- 去结算按钮：无有效勾选项时禁用

### 5.5 下单页 `/checkout`

- 收货地址：选择已有地址 / 新增地址。默认选中默认地址
- 商品清单（只读，来自购物车勾选项或立即购买）
- **折扣码输入**：输入后点击「使用」调用试算接口，成功展示减免金额与折扣码名称，支持取消
- 买家备注（选填，200 字以内）
- 金额明细：商品小计、优惠、运费、应付合计
- 提交订单

**提交订单时服务端必须（强约束，同一事务）**：
1. 校验所有变体状态与价格（价格以数据库为准，与前端不一致时以数据库价格重算）
2. 重新计算折扣与运费，**不采信前端金额**
3. 锁定耗材行，校验并写入预扣
4. 占用折扣码
5. 创建订单、订单项（含 BOM 快照）
6. 清除购物车中对应商品

任一步骤失败则整体回滚，返回明确错误（如「黑色 PLA 库存不足，请减少数量」）。

### 5.6 支付页 `/checkout/pay/[orderNo]`

- 展示订单号、应付金额、倒计时（距 `reserved_until`）
- 调用创建支付接口，跳转支付宝收银台（`alipay.trade.page.pay`）
- 用户支付后跳回 `return_url`，落地本页
- **本页轮询** `GET /api/payments/:outTradeNo/status`，每 3 秒一次，最长 5 分钟
- 支付成功 → 跳转订单详情；倒计时归零 → 展示订单已取消

**强约束**：同步跳转 `return_url` **禁止**作为支付成功的判定依据，仅用于页面跳转。订单状态**只**由异步回调 `notify_url` 变更。

### 5.7 订单中心 `/account/orders`

- 订单列表：按状态 Tab（全部、待支付、生产中、待收货、已完成、已取消）
- 订单卡片：订单号、下单时间、商品缩略、金额、状态、操作按钮
- 操作：去支付、取消订单（仅待支付）、查看物流、确认收货
- 订单详情页 `/account/orders/[orderNo]`：
  - 状态进度条（下单 → 支付 → 生产 → 发货 → 完成）
  - 生产进度明细：展示每个订单项的生产任务状态
  - 收货信息、金额明细、物流单号
- 地址管理 `/account/addresses`：增删改查、设为默认

## 6. 后台功能 `/admin`

### 6.1 登录与工作台

- 用户名 + 密码登录，密码错误 5 次锁定 15 分钟
- 工作台看板：今日订单数、今日销售额、待排产任务数、待发货订单数、**低库存耗材预警列表**（`stock_grams - reserved_grams <= safety_grams`）

### 6.2 订单管理

- 列表：订单号、用户、金额、状态、下单时间、支付时间
- 筛选：状态、时间范围、订单号/手机号搜索
- 详情：完整订单信息、订单项（含 BOM 快照展示）、金额明细、支付记录、操作日志
- 操作：
  - 备注（内部备注）
  - 发货：填写快递公司 + 单号 → 订单转 `shipped`
  - 取消订单（仅待支付）
  - 发起退款：填写金额与原因，**可勾选「回滚耗材库存」**；全额退款时同时回滚折扣码使用次数
- 导出：按筛选条件导出 CSV

### 6.3 生产管理

- 生产看板：按状态分列（待排产 / 打印中 / 后处理 / 已完成 / 失败）
- 任务卡片：订单号、商品变体、数量、耗材需求明细、下单时间
- 操作：开始打印（可填打印机名）、转后处理、标记完成、**标记打印失败**（触发重打扣料，需二次确认并展示将扣减的耗材量）
- 筛选：按耗材筛选（便于集中打印同色批次）

### 6.4 商品管理

- **分类管理**：树形结构，增删改、排序、显隐
- **商品（SPU）管理**：
  - 列表：主图、名称、分类、价格区间、变体数、状态
  - 编辑：基础信息、Markdown 描述、图集上传（Supabase Storage）、GLB 预览文件上传、分类、推荐位、上下架
- **变体（SKU）管理**（商品编辑页内）：
  - 属性维度定义（尺寸/材质/颜色），支持笛卡尔积批量生成变体
  - 每个变体：SKU 编码、价格、划线价、成品重量、预计打印工时、变体图、启用开关
  - **BOM 配置**：为每个变体添加耗材条目（耗材 + 克数），支持多条
  - **保存校验**：启用的变体必须至少配置一条 BOM，否则拒绝保存并提示
  - 变体行实时展示当前可售数量（只读）

### 6.5 耗材管理

- 列表：编码、名称、类型、颜色（色块）、规格、在库克数、预扣克数、**可用克数**、安全库存、损耗率、状态
- 排序与高亮：可用克数低于安全库存的行标红置顶
- 新增/编辑：编码、名称、类型、颜色名与色值、品牌、规格、单价（元/kg）、安全库存、损耗率、供应商、备注
- **入库**：填写克数、批次号（选填）、单价、备注 → 写 `purchase_in` 流水
- **手动调整**：填写调整后的克数与原因 → 写 `adjust` 流水，记录差额
- **流水查询**：按耗材、类型、时间筛选，展示变动前后快照与关联订单
- **停用**：停用后所有关联该耗材的变体立即不可售，停用前需展示受影响的变体数量并二次确认
- **关联查看**：查看使用该耗材的所有商品变体

### 6.6 用户管理

- 列表：手机号、昵称、注册时间、订单数、累计消费额
- 详情：基础信息、地址列表、订单历史
- 操作：禁用/启用账号（禁用后无法登录与下单）
- **禁止**在后台展示或导出用户密码相关信息

### 6.7 折扣码管理

- **优惠规则（promotions）**：
  - 新增/编辑：名称、类型（满减 / 折扣 / 包邮）、优惠值、使用门槛、封顶金额、适用范围（全场 / 指定分类 / 指定商品）
- **折扣码（discount_codes）**：
  - 列表：码、关联规则、类型（常驻/限次）、已用/总量、单用户限次、有效期、开关状态
  - 新增：手动输入码（自动转大写，唯一校验）、选择规则、类型、总次数、单用户限次、生效与失效时间
  - **一键开启/关闭**（`is_active`），即时生效
  - 核销记录：查看使用该码的订单列表
- 第一版适用范围仅需实现「全场」，但表单与字段需完整保留

### 6.8 权限管理（超管）

## 8. 验收标准

实现完成需通过以下场景验证：

1. **可售联动**：后台将「PLA-黑色」库存调至 0，前台所有使用该耗材的变体在 60 秒内变为不可选；恢复库存后重新可选
2. **多耗材 BOM**：为一个变体配置两种耗材（100g 白 PLA + 20g 黑 PLA），其中黑 PLA 仅剩 15g，该变体不可售
3. **损耗率生效**：耗材损耗率 10%，BOM 为 100g，下单 2 件后 `reserved_grams` 增加 220g
4. **预扣释放**：下单不支付，31 分钟后订单自动取消，`reserved_grams` 恢复原值，流水中有 `reserve` 与 `reserve_release` 两条记录
5. **支付幂等**：对同一笔支付重复投递 3 次回调，订单仅扣料一次，`material_stock_movements` 中仅一条 `consume` 记录
6. **金额篡改防护**：前端篡改 `payable_amount` 提交，服务端以数据库价格重算，创建的订单金额正确
7. **折扣码限次**：限次码剩余 1 次，两个用户并发下单，仅一人成功，另一人收到「折扣码已用完」
8. **单用户限次**：`per_user_limit = 1` 的常驻码，同一用户第二次使用被拒绝
9. **折扣不减运费**：满 100 减 20 的码，商品小计 100 元 + 运费 10 元，应付为 90 元
10. **取消回滚码次数**：使用折扣码下单后取消订单，`used_count` 回到原值，该码可再次使用
11. **重打扣料**：标记打印失败后，`stock_grams` 再次扣减对应克数，流水类型为 `reprint_loss`
12. **状态流转完整**：一笔订单从下单走到已完成，各阶段状态与订单中心展示一致
13. **权限隔离**：无 `order:refund` 权限的运营账号调用退款接口返回 403
14. **并发扣料**：10 个并发请求下单同一变体（可售数量为 5），恰好 5 单成功，无超卖
