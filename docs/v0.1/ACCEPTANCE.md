## v0.1 演示数据

执行 `pnpm demo:seed` 会先清理上一套固定 ID 的演示数据，再重新生成完整数据并输出随机后台密码。数据覆盖：

- 4 种耗材，包括正常库存、低库存和库存不足场景；
- 3 个商品、4 个变体，以及单耗材和多耗材 BOM；
- 满减、折扣和包邮三种优惠规则及折扣码；
- 3 个虚构用户、2 个虚构地址和购物车；
- 待支付、已支付、生产中、待发货、已发货、已完成、已取消、退款中、已退款 9 种订单状态；
- 关联的支付、库存流水、生产任务、物流、退款和折扣核销数据；
- 站点信息、Banner、区域运费规则和不同权限的演示运营账号。

数据一致性可通过 `pnpm demo:check` 复验；`pnpm demo:reset` 只移除固定 ID 的 v0.1 演示数据，并恢复播种前备份的站点配置。生产环境默认禁止执行，隔离验证环境必须显式设置 `ALLOW_DEMO_DATA=true`。
