# 3D 打印成品独立站 v0.1 Release Notes

- 发布日期：2026-08-30
- Git Tag：`v0.1`
- 定位：可部署到境外隔离环境的业务验证版

> [!WARNING]
> v0.1 不是中国大陆生产版。禁止接入真实用户或存储真实个人信息；支付宝仅用沙箱账号，不产生真实资金流转。

## 功能范围

- 前台：首页、分类与商品列表、商品详情、实时可售数、购物车、收货地址、下单试算、用户订单中心。
- 库存：多耗材 BOM、安全库存、损耗率、预扣/释放/实扣、入库/盘点/重打损耗流水，并发行锁防超卖。
- 交易：运费规则、满减/折扣/包邮、限次折扣码、订单状态流转、支付 Provider、Mock 支付、支付宝 RSA2 接入、退款、物流。
- 生产：生产任务队列、开始打印、后处理、完成、失败与重打扣料。
- 后台：工作台、耗材、分类、商品与变体、订单、优惠规则、折扣码、生产、用户、管理员、角色权限、站点与运费配置。
- 系统：后台独立 JWT/RBAC、操作审计日志、手机 OTP 限流、统一错误码、结构化日志、上传安全校验。
- 定时任务：每分钟释放过期订单、自动确认收货、低库存汇总，附 system crontab 安全模板。

## 数据与验收

- 提供可重复的 `demo:seed` / `demo:check` / `demo:reset`，覆盖耗材到商品、用户到订单的完整虚构数据。
- PRD §8 的 14 项验收全部通过，包括 10 个并发订单竞争 5 份可售库存时恰好 5 成功、5 失败且无超卖。
- 验收入口：`pnpm test:acceptance`；详细证据见 [ACCEPTANCE.md](./ACCEPTANCE.md)。
- 生产构建、TypeScript、ESLint、25 项单元测试与安全审计通过；客户端 bundle 无 Service Role/支付私钥，依赖无已知漏洞。详见 [SECURITY.md](./SECURITY.md)。

## 部署说明

v0.1 提供完整应用与数据库迁移，但本 Tag 未包含特定服务器的可用生产部署结果。下一阶段以 `docs/CHANGES-v0.2.md` 为增量规范：

1. T104 初始化华为云新加坡主机、域名、HTTPS、swap 与防火墙。
2. T105 完成容器化发布、健康检查、Nginx 与 system cron 安装。
3. T106 在公网 HTTPS 环境完成支付宝沙箱签名、回调、幂等、金额篡改防护和退款验证。

Supabase 必须使用新加坡 `ap-southeast-1` 区域，`DATABASE_URL` 使用 Supavisor `6543` transaction 模式。部署参数与安全警告见项目根目录 README。

## 已知限制

- T044 的 3D 实时预览为可选延后项，当前仅保留可空的模型 URL 与基础预览能力，不阻塞交易主链路。
- 全链路自动验收使用 Mock Provider；支付宝 RSA2 代码已接入，真实沙箱公网回调属于 T106。
- Supabase Cloud 在中国大陆访问可能不稳定；境外域名无法 ICP 备案，可能影响支付宝生产商户号审核。
- 手机号、地址等个人信息存储于境外涉及个人信息出境合规，所以本版本只允许虚构测试数据。
- 沙箱退款的返回码和时序与生产可能不同，正式收款前必须再验证。
