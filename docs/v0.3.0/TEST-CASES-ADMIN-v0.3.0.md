## 错误码速查（后台 / 系统侧常用）

| 码 | HTTP | 含义 | 主要出现路径 |
|---|---|---|---|
| 40101 | 401 | 未登录 / 会话失效 | 后台登录态失效、定时任务鉴权失败 |
| 40301 | 403 | 无操作权限 | 越权访问后台接口 / 页面 |
| 40915 | 409 | 同一订单已有 pending 申请 | 客户侧提交（见客户侧文档） |
| 40916 | 409 | 该商品当前状态不允许客户申请 | 客户侧提交（printing 商品普通原因） |
| 40917 | 409 | 申请单状态不允许该操作 | 后台重复审核 / 已撤销申请 |
| 40918 | 409 | 退款金额超过该商品可退余额 | 后台直接退款 / 审批 |
| 40919 | 409 | 尺寸 / 装配例外只适用于已进入打印流程的商品 | 客户侧提交 |
| 40920 | 409 | 同一退款处理中 / 3 分钟冷却租约内 | 续记 / 作废 |
| 40921 | 409 | 退款明细计算结果为 0 | 后台直接退款 |
| 40922 | 409 | 渠道明确拒绝，可修正后重新发起 | 后台直接退款（首次明确拒绝） |
| 40923 | 409 | 渠道结果不确定，必须人工复核 | 续记 / 作废 |
| 40924 | 429 | 同一用户一小时内凭证上传超 20 次 | 客户侧上传 |
