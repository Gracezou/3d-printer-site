# v0.3.0 后台运营体验验收

日期：2026-10-15。分支：`release-v0.3.0`。

## 范围和环境

本批包含后台统一布局、权限/设置/分类交互、耗材录入简化、商品 Slug 和编辑保护。没有部署、修改线上配置或写入真实业务数据。

浏览器预览使用真实页面组件和本地内存模拟接口，不连接数据库。此验证只证明页面交互，不代替接口鉴权、真实持久化或线上业务验收。

## 已完成的浏览器检查

- 权限：角色列表和分组编辑分栏显示；分组全选后计数从 1/3 更新为 3/3，总数同步更新，保存按钮启用。
- 设置：修改站点名称后保存，提示成功并恢复无待保存状态；切换运费规则分组时 URL 同步更新。
- 响应式：390×844 设置页导航横排、字段单列显示，保存栏可见。
- 分类：折叠一级分类后刷新仍保留折叠状态；搜索子分类名称时显示父节点与匹配子节点；新增分类抽屉正常打开/关闭，并保留列表筛选。
- 未保存提醒：触发了浏览器原生确认框，但当前预览工具无法完成确认框的接受/取消操作，不能标为完整通过。

## 部署后人工验收（待执行）

1. 使用只读账号及可管理账号检查角色编辑/分组全选/保存的权限差异；修改角色后核对实际账号权限，无越权。
2. 设置两组分别编辑、保存、刷新，检查互不覆盖；失败时草稿不丢失。
3. 分类、耗材、账号抽屉验证鼠标、Tab、Escape、遮罩和取消操作；有修改时分别选择继续编辑/放弃，保存中不可意外关闭。
4. 耗材新增/编辑核对生成编号和名称及重复编号提示，采购日期加订单号入库后核对原字符串存储值。
5. 商品基础信息与规格同时修改，分别保存，另一组草稿应保留；新商品 Slug 可用，旧商品链接不改变。
6. 在耗材、商品、订单和账号列表设置筛选及分页，刷新后应还原；分类搜索与折叠应还原。
7. 手机端检查抽屉、长表单保存栏及横向表格操作；页面刷新、关闭、普通链接跳转和显式取消时检查未保存提醒。

限制：未保存保护不包含浏览器前进/后退引起的客户端导航；本批未执行真实支付/退款回归，B4 沙箱门禁仍需独立完成。
