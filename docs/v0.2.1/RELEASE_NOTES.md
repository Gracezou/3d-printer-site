# v0.2.1 Release Notes

发布日期：待预生产 Beta 验收完成后确定。

## 本次更新

- 将应用版本更新为 `v0.2.1`，发布流水线支持 `release-v0.2.1` 分支，并在健康检查版本中保留构建提交 SHA。
- 生产容器改用不依赖本地 `.env.dev` 的构建命令，公开站点地址可通过 GitHub 仓库变量 `PREPROD_SITE_URL` 注入。
- 新增带完整注释的预生产/生产环境变量模板，明确 Supabase、支付宝沙箱、邮箱 Auth、后台鉴权、Cron 和站点配置边界。
- 新增受双重保护的预生产数据重置工具，保留管理员、系统角色及非演示 Auth 用户资料，每个业务模块只写入一条互相关联的参考实例。
- 预生产站点采用“层光造物”正式品牌文案，移除数据中的“演示站”“测试商品”等展示内容。
- 补充预生产部署、支付通知幂等、部分退款、全额退款、库存返还与回滚验收步骤。
- 修复支付宝同步返回使用容器内部地址的问题，确保付款后返回公开站点；待支付状态增加支付宝主动查询补偿，异步通知漏投时仍可按金额校验和原有幂等事务安全入账。
- 修复分类商品数量子查询字段未限定导致在售商品计数为零的问题。

## Beta 限制

- 支付仅允许支付宝沙箱，不产生真实资金流转。
- 境外 Supabase 只用于受邀验证，不录入真实手机号、地址等个人信息。
- IP + HTTP 可用于页面冒烟检查；支付宝异步通知的完整验收需等 HTTPS 域名可用后进行。
- 执行数据重置前必须先确认数据库目标并建立可恢复点。
