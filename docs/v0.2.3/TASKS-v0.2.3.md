## 1. 范围与完成定义

本版本按以下顺序完成：

1. 盘点并加固上海服务器；
2. 从上海和新加坡分别测量到 Supabase 新加坡区的数据库延迟；
3. 延迟门禁通过后，将应用部署到上海并完成真实接口、下单事务和并发扣料复测；
4. 完成备案域名、HTTPS 与外部平台地址切换；
5. 形成验收报告、回滚说明和发布记录。

本版本不修改数据库结构，不实施 `TECH_SPEC.md` §13.2 的下单存储过程重构，不切换支付宝生产通道。X3 测试商品属于并行运营数据，不扩大基础设施版本范围。

任务状态：`[ ]` 未开始，`[~]` 进行中或等待外部条件，`[x]` 已完成且有证据，`[-]` 经确认跳过。
