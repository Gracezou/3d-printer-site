## 1. 范围与完成定义

本版本验证当前新加坡主机、Cloudflare 和域名形态下，支付宝生产通道能否完成一笔实付 0.01 元的支付、全额退款与库存核对。

只执行配置、限定范围的数据操作和验收记录，不修改业务代码或数据库结构。购物路径优化顺延 v0.2.4；部分退款验证归 v0.3.1；邮件通知归 v0.3.2。

任务状态：`[ ]` 未执行，`[~]` 进行中或待外部条件，`[x]` 已完成且有证据。用户已授权分批执行、每批完成自动提交并继续下一批；进入下一批仍须满足对应前置条件。

完成路径有两种：

- 支付验证路径：P1–P5 满足 → 数据试算 → 配置切换 → 支付及退款 → 定点清理 → 结论归档。
- 前置阻断路径：P1/P2 确认不具备 → 不进入生产资金测试 → 记录实际原因并交由 v0.3.0 处理。仅凭“尚未提供资料”不能认定现有部署形态无法签约。
