# v0.3.1 Release Notes

状态：Stage 候选，尚未完成 T226 人工验收；不是生产正式发布声明。

## 主要更新

- 用户端采用轻量扁平布局，统一商品发现、购物车、结算和账户体验；首页商品以主图为主。
- 商品按「款式＋配色」选择，主图随选择切换；多色配色按实际耗材用量计算库存，不足时禁用。
- 后台统一维护款式售价、成品重量和单色用量；支持指定耗材或全部耗材自动同步；旧商品先预览整理，保留原 SKU。
- 购物车连续操作即时反馈、失败局部恢复，结算试算失效保护与防重复下单；折扣码入口折叠展示。
- 订单中心统一操作按钮、筛选分页恢复、商品展开及实付/退款信息；修复后台保存后仍提示未保存的问题。
- 新增订单、售后及开模业务邮件队列，支持去重、重试、未知投递隔离和 Stage 白名单。真实发信需完成独立 SMTP/发件域配置后再开启。
- 备案号更新为「鲁ICP备2026057815号」。

## 升级注意

先备份并执行 0009–0011 迁移，再部署应用。保留历史订单用料快照，不自动改写旧商品；回滚保留新增结构，暂停旧版本的商品/耗材配置写入。详见 [T227 操作及迁移说明](./T227-STYLES-AND-COLORWAYS.md) 和 [邮件契约](./B0-B1-BASELINE-AND-EMAIL.md)。

3D 模型展示/实时换色、自由分区配色、公开领券中心不在本期范围。真实邮件、真实支付回跳、实际素材及真机体验仍须完成 T226。安全依赖例外只适用于 Stage，不代表生产安全门禁通过。

回归结果及性能边界见 [B4 验收记录](./B4-REGRESSION-AND-PERFORMANCE.md)。
