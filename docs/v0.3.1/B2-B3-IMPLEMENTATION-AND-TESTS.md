# v0.3.1 B2/B3 实现与本地验收

日期：2026-10-16。分支：`release-v0.3.1`。本记录不表示已部署或整个版本已完成。

## 范围与交付

- 首页：缩短首屏文案区，让机型选择更早出现；推荐与新品卡片只显示主图链接，无辅图、轮播或悬停换图。
- 商品发现：新增真实关联机型筛选；移动端可展开条件，已选条件可逐个移除；URL 保存搜索、机型、价格和排序，支持刷新和前进后退。
- 关联规格：切换尺寸时只清除不兼容的已选维度，不自动替用户选颜色；可取消选择、重选，售罄和未完成规格均不能购买。
- 适配核对：所选机型随列表链接进入详情，登录回跳保留参数；错配有提示并阻止购买。购物车、结算、订单显示关联范围；订单标为「商品当前适配」，不是下单时的历史机型快照。本批没有新增数据库字段。
- 扁平布局：非详情页统一紧凑圆角、边框、控件和焦点样式，保留品牌色；不改后台及详情页整体展示。
- 购物车：数量/删除乐观更新，同一商品请求串行，合并排队中的连续修改；失败仅恢复对应商品；角标避免旧响应覆盖，保存未完成时不能结算，失败可刷新核对。
- 结算：地址/优惠变化使旧试算失效并中止旧请求；试算失败可重试；同步提交锁阻止连续点击，成功订单不会因清理浏览器存储失败而再次提交。费用规则未改动。
- 账户：订单/售后优先导航、状态操作提示、中文售后状态及原因、加载失败恢复入口；登录只允许安全站内回跳；地址编辑可返回结算。
- 可访问性：地址弹窗焦点循环、Escape、焦点恢复；核心按钮与数量控件触控面积、异步状态播报、语义标签及减少动画规则。

机型关联查询按父记录聚合读取，避免每张卡片再发一次请求；在隔离 PostgreSQL 验证了筛选和字段限定，不依赖前端猜测适配关系。

## 复测方式

使用专用本地测试数据库（PostgreSQL，已应用迁移 0000–0009），不要指向 dev/Stage/生产共享库。测试自动创建及清理 `f031…` 固定前缀的专用夹具，仅允许本地主机连接，不支持并发重复运行。

```sh
pnpm exec playwright install chromium
DATABASE_URL='<专用本地 PostgreSQL 连接串>' pnpm test:shop:e2e
pnpm lint
pnpm typecheck
pnpm test
```

浏览器测试自行启动本地 5103 端口，不复用已有服务，不发送真实邮件或支付。已有数据服务脚本请用显式本地 `DATABASE_URL` 直接运行 `pnpm exec tsx scripts/test-cart-service.ts` 等；不要使用自动加载 `.env.dev` 的快捷脚本来执行隔离测试。
