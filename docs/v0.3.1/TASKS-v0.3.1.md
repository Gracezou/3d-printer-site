## B1 · 通知能力（原 v0.3.1）

### T217 业务邮件基础设施

- [x] 建立业务邮件队列、唯一去重键、模板类型和安全的重试/失败状态；事务内仅入队，定时任务批量发送并防止并发重复认领。
- [x] 配置独立 SMTP 适配、发件域与环境变量模板；日志遮蔽收件人及凭据，不在任务失败日志泄露邮件正文中的个人信息。
- [x] 使用隔离数据库和假邮件提供方验证发送成功、超时/未知、重试、重放与坏消息隔离；未知投递结果转人工核实，不盲目重发；邮件故障不回滚订单事务。

### T218 订单与售后邮件

- [x] 支付成功、开始生产、发货、审核通过/驳回及退款成功按事件矩阵入队；只发给订单所有者。
- [x] 邮件状态、订单编号、链接与站内真实状态一致；重放回调或重复执行 Cron 不能重复入队/认领，取消/失败不能误发成功邮件。
- [x] 更新售后页「本期不发送邮件」等过期说明，并保留站内查询入口。

### T219 意向登记开模通知

- [x] 仅机型已开模且存在可见、在售、有可售库存的关联商品时，向该机型待通知登记邮箱入队；无可购商品或仅勾选已开模时不发。
- [x] 同一登记/开模事件幂等；明确失败可重试、未知结果转人工，成功后更新登记状态；通知链接落在真实机型页面。
- [x] 更新机型登记页「本期仅收集意向」文案；Stage 受控邮箱的真实投递验收并入 T226。

## B2 · 商品发现与展示（原 v0.3.2 + 本次四项）

### T220 机型适配与筛选

- [x] 首页机型选择更早可见；列表移动筛选及条件展示清晰，刷新/前进后退不丢条件；浏览器确认筛选未重载整个文档。
- [x] 列表所选机型随链接进入详情及登录回跳，误配时阻止购买并提供恢复入口；购物车、结算及订单展示真实关联机型。订单明确标为「商品当前适配」，本批不新增历史机型快照，不将关联范围伪装成用户历史选择。
- [x] 相近型号不默认兼容，无商品时提供恢复入口；适配范围只来自可见品牌/机型的商品关联。

- [x] 单元测试与浏览器验证稀疏组合切换、取消、重选及不同选取顺序。详情页固定购买入口移至 T227。
