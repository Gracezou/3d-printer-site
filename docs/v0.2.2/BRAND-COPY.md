## 0. 产品定位（本文件的前提）

> **一家专做电子阅读器保护壳的按单打印店。**
> 覆盖阅星瞳、Kindle、掌阅、文石等主流品牌，也做已停产、大厂不再供货的老机型。
> 注塑开模要卖上千个才回本，3D 打印按单生产没有开模成本，一个型号几十人要也做得起。
> **下一个开哪个机型，由需求量决定**——用户可以登记意向，够人要就开模。

三层：

| 层 | 内容 |
|---|---|
| 品类 | 电子阅读器保护壳（小挂件小玩具为周边，不进一级导航） |
| 差异 | 冷门机型与停产老款也有；按单打印，不压库存 |
| 参与 | 没有你的型号可以登记，需求量决定开模顺序 |

**用户是带着确定目标来的**——他有一台什么机器，就要那台机器的壳。因此首页第一屏的核心是**设备选择器**，不是商品网格。

基调：**主标题走意象，副标题落地。** 主标题负责气质，副标题负责把品类和差异点说清楚。

| # | 项 | **文案** |
|---:|---|---|
| 2.1 | 主张句（H1） | **量卷裁衣** | |
| 2.2 | 副标题 | 为每一台电子阅读器，做一件合身的壳。新品到停产旧机，按单打印，一台也做。 | |
| 2.3 | 设备选择器标签 | 选择你的机型 | |
| 2.4 | 搜索框 placeholder | 输入品牌或型号，比如 阅星瞳 X4 | |
| 2.5 | 轮播第二屏主标题（可选，未定） | 旧卷亦有新衣 | |
| 2.6 | 轮播第二屏副标题（可选，未定） | 大厂不再供货的老机型，我们仍在做。按单打印，一台起。 | |

> **2.1 的由来**：化用「量体裁衣」，把「体」换成「卷」（书卷即阅读器）。四字成语化用，不生僻，且精确表达「按机型定制」这件事——每台机器尺寸不同，壳也该不同。
>
> **2.2 一句话讲完三件事**：品类（电子阅读器保护壳）、覆盖范围（新品到停产旧机）、生产方式（按单打印，一台也做）。
>
> **主行动不是按钮而是设备选择器**——用户应在三秒内走到自己的机型页。

### ⚠️ H1 意象化的 SEO 补偿要求

「量卷裁衣」四个字**不含任何品类关键词**，搜索引擎无法从 H1 得知本站卖什么。H1 是页面 SEO 权重最高的元素，这是一次有意识的取舍：**保住 H1 的美感，把关键词补在别处。**

因此以下四处**必须**包含核心品类词，缺一不可：

1. **2.2 副标题**——紧邻 H1，须含「电子阅读器」与「壳」
2. **7.1 首页 title**——须含「电子阅读器保护壳」
3. **7.2 首页 description**——须含品类词与主要品牌名
4. **6.2 首页 SEO 正文**——首段即出现「电子阅读器保护壳」

实施细则见 `CHANGES-v0.2.2.md` 的 T122 与 T128。

## 4. 交付流程说明

⚠️ **本节文案一旦对外即构成对用户的承诺。**
⚠️ 首页、机型页、商品页、结算页四处的交期表述必须一致。

| # | 项 | **文案** |
|---:|---|---|
| 4.1 | 流程步骤 | 下单 → 排产打印 → 去支撑打磨 → **装机复核** → 打包发货 | |
| 4.2 | 打印周期 | **7 天内发出**（自然日；自下单起算，含打印、去支撑打磨与装机复核） |
| 4.3 | 发货节奏 | 装机复核通过后当日或次日发出，整体不超过 7 天 |
| 4.4 | 高峰期说明 | 订单集中时排产可能顺延，我们会在订单状态里同步进度，不会让你干等。 | |
| 4.5 | 整段说明 | 见下 | |

**4.5 建议草案**

> 我们不囤货。你下单之后，这件壳才进入打印队列——按你选的耗材和颜色逐层成形，通常需要 7 天以内。打印完成后要手工去除支撑、打磨接缝，再装到对应机型上复核一遍卡扣和开孔，确认没问题才打包寄出。
>
> 这比从仓库发货慢，但换来的是：冷门机型和停产老款也能有壳。注塑开模要卖上千个才回得了本，所以大厂只做热门型号；按单打印没有开模成本，一个型号只有二十个人要，我们也做得起。

> ✅ **「装机复核」已确认可执行（2026-09-10）**，作为正式对外承诺保留。保护壳是精密配合件，用户最怕装不上，这一步是最值钱的信任点。
> ⚠️ 一旦对外，**每一单都必须真的执行**。若将来因产能变化无法逐单复核，须先改本文件与页面文案，再调整流程。

**6.2 建议草案**

> 书衣是一家专做电子阅读器保护壳的按单打印店，覆盖阅星瞳、Kindle、掌阅、文石等主流品牌，也做已经停产、大厂不再供货的老机型。

> 墨水屏阅读器的机型非常碎片化，每个型号尺寸都不一样，壳不通用。注塑开模的成本要靠销量摊平，所以厂商只愿意做最热门的那几款——冷门型号和停产老款的用户，往往全网都买不到一件合适的壳。

>
> 如果站内还没有你的型号，可以登记意向。同一机型的登记人数够了，我们就安排建模和打样，做出来第一时间通知你。下一个做哪台机器，由需求决定。

## 9. 商品与机型命名规范

保护壳涉及第三方设备品牌，命名方式有法律边界。

| # | 规则 | 说明 |
|---:|---|---|
| 9.1 | ✅ 可以 | 「适用于 Kindle Paperwhite 5」——描述性使用，说明兼容性 |
| 9.2 | ❌ 不可以 | 使用对方的 logo、商标图形或包装视觉 |
| 9.3 | ❌ 不可以 | 命名为「Kindle 保护壳」这种让人误以为是官方产品的写法 |
| 9.4 | ❌ 不可以 | 逆向复制原厂壳的外观设计 |
| 9.5 | ✅ 可以 | 自行建模的功能性外壳，尺寸匹配设备是安全的 |

> 本条不构成法律意见。若将来规模扩大，建议就商标描述性使用与外观设计咨询专业人士。
